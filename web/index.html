SatelliteSim — browser port

A server-less static build of the mission-control panel. The whole simulation is ES modules under web/src/, parity-tested against the Julia package; the four pages below run it in-process.

mission control Configure, fly, and explore a mission: free return, Earth orbit, suborbital hop or lunar landing. vehicle builder Stack stages, strap-ons and engines, and see the rocket the numbers actually imply. analysis Telemetry plots, the event log, parameter sweeps and the solver. launch view The 3D ascent, cislunar coast, entry and lunar descent.
Serve web/ at the root (e.g. node web/serve.mjs) so the pages' absolute /static/… imports resolve.
